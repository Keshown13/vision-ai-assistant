\### 遇到的问题

\- Dify 采用 Docker 部署，容器访问宿主机 8000 端口出现超时

\- 原因：Docker 容器与宿主机的网络隔离，Windows 防火墙拦截端口访问

\- 解决方案思路：后续切换为本地源码启动 Dify，或配置 Docker 端口映射、防火墙放行规则
