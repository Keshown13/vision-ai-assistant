\# AI 视觉问答智能体



本项目对应人工智能协会创智部二面实战题目，完成本地大模型部署、YOLO训练与推理部署、Dify智能体搭建三大核心任务。



\## 已完成任务

\### 1. 本地大模型部署

\- 部署工具：Ollama

\- 部署模型：qwen2:1.5b

\- 能力：本地纯CPU推理，支持对话，自带标准API接口

\- 启动方式：命令行执行 `ollama run qwen2:1.5b`



\### 2. YOLO 跑通

\#### 2.1 模型训练

\- 基于 ultralytics 库，使用 YOLOv8n 预训练模型

\- 数据集：官方 coco8 小型数据集

\- 训练参数：epochs=3，batch=4，imgsz=640

\- 训练产出：模型权重、精度曲线、训练日志，保存在 `yolo/runs/detect/train`



\#### 2.2 实时推理部署

\- 基于 Python + Flask 封装为 HTTP 接口服务

\- 服务端口：8000，监听 0.0.0.0

\- 调用方式：POST 请求 /detect 接口，form-data 上传图片，返回识别结果



\### 3. 智能体搭建

\- 搭建工具：Dify

\- 模型提供商：本地 Ollama 部署的 Qwen2 大模型（API接入）

\- 应用形态：Web 端看图问答应用

\- 工作流：用户上传图片 + 输入问题 → 调用 YOLO 接口识别物体 → 大模型基于识别结果生成自然语言回答



\## 技术栈

\- 大模型：Ollama + Qwen2-1.5B

\- 视觉识别：Ultralytics YOLOv8

\- 接口封装：Flask

\- 智能体编排：Dify

\- 版本控制：Git
